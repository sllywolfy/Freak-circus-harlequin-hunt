# Freak-circus-harlequin-hunt

An action-packed 2D shooter game built with Python and Pygame. Battle against freak circus harlequins as you dodge, aim, and survive!


## ✨ Features

* **Player Movement:** Smooth, responsive movement around the arena.
* **Shooting Mechanics:** Aim and fire to defeat incoming harlequin enemies.
* **Circus Theme:** Featuring custom artwork and freak circus harlequin enemies.


## 🎮 Game Controls

| Action | Control |
| --- | --- |
| **Move** | `W`, `A`, `S`, `D` or Arrow Keys |
| **Shoot** | Spacebar |


## 🛠️ Requirements & Setup

If running from source, ensure you have Python installed, then install Pygame:

```bash
pip install pygame

```


## 🚀 How to Open and Run the App

### Option 1: Run the Executable (Recommended)

1. Download or locate the `shooter_game.exe` file in the project directory.
2. Double-click **`shooter_game.exe`** to launch the game directly.

### Option 2: Run from Python Source

1. Open a terminal or command prompt in the project folder.
2. Run the main Python script:
```bash
python main.py

```
